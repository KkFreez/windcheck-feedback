# CityKIS Wind:Check – Feedback

Wind:Check is an experimental forecast system for morning wind at Lago di Cavazzo.

This repository is only for feedback, observations, bugs and ideas.
The forecast system itself is developed separately.

## Feedback is very welcome

Especially useful:

- forecast vs. what actually happened at the lake
- local weather observations
- wrong or misleading classifications
- bugs on the website
- ideas for a simpler or more useful interface

## Italiano

Wind:Check è ancora un laboratorio.

Qui puoi lasciare:

- osservazioni sulle previsioni
- confronto tra previsione e vento reale
- errori o classificazioni sbagliate
- bug della pagina
- idee e suggerimenti

Le osservazioni di chi conosce bene il Lago di Cavazzo sono particolarmente utili.

👉 Vai su **Issues → New issue** per lasciare un feedback.

Website: https://citykis.net/wind/
